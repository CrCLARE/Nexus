# Nexus 贡献者许可协议 (Individual Contributor License Agreement)

感谢您对 Nexus 项目（以下简称“本项目”）的关注与贡献！本协议旨在明确您向 CrCLARE Studio（以下简称“维护者”）提交贡献时所涉及的知识产权许可，以保护您、维护者以及广大用户的合法权益，并支持本项目“开源+商业”双轨制的可持续发展。

在向本项目提交任何 Pull Request 或代码贡献前，请仔细阅读本协议。**您通过向本项目提交贡献，即表示您完全接受并同意本协议的全部条款。**

### 1. 定义
*   **“贡献”**：指您有意提交给维护者的任何原创作品，包括但不限于源代码、文档、设计图、配置等。
*   **“维护者”**：指 CrCLARE Studio 及其指定的项目核心管理人员。

### 2. 版权许可授予（核心条款）
您**保留**您所贡献代码的著作权（版权）及所有相关的署名权（Moral Rights）。

为了项目的健康发展，您在此授予维护者一项**永久的、全球性的、非独占的、免版税的、不可撤销的**版权许可。该许可允许维护者：
1. 复制、修改、分发您的贡献及其衍生作品。
2. **再许可（Sublicense）**：维护者有权将您的贡献，以**开源许可证（包括但不限于 GNU AGPLv3）**或**任何商业闭源许可证**（如未来的 Nexus Pro 商业版）进行授权和分发。
3. **您理解并同意**：维护者行使上述商业再许可权利时，无需另行向您支付任何费用或版税，且您不可撤销此授权。

### 3. 尊重与保留署名权（承诺条款）
维护者极其尊重您的智力劳动成果。在您签署本协议后：
1. 在开源社区版本中，维护者将在 `CONTRIBUTORS.md` 文件（或类似贡献者名单）中永久列出您的名字。
2. 如果您希望在您提交的特定源文件头部保留您的版权声明（如 `@author 您的名字`），维护者将予以尊重并保留（除非该文件已被大幅重构）。

### 4. 专利许可授予
您在此授予维护者及软件接收者一项永久的、全球性的、免费的、不可撤销的专利许可，允许其制造、使用、销售、进口您的贡献。如果您就本项目或您的贡献提起任何专利侵权诉讼，本协议授予您的所有许可将自动终止。

您声明并保证：
1. 您有权提交该贡献，且该贡献是您的原创作品。
2. 您的贡献没有侵犯任何第三方的知识产权。
3. 如果您的雇主对您所提交的贡献拥有知识产权，您已获得雇主的明确授权，允许您提交该贡献。

您提供的贡献均按“现状（AS IS）”提供，不附带任何明示或暗示的担保。在任何情况下，您均不对因使用您的贡献而产生的任何损害承担责任。

您通过向本项目提交 Pull Request，并在 GitHub 提示时回复确认（或通过 CLA Assistant 等自动化工具点击同意），即表示您已阅读、理解并自愿受本协议条款的法律约束。
